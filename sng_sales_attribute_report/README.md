# Facturación por atributos

Asistente multicompañía para analizar facturas y notas de crédito por valores
de atributos de producto. El total principal usa únicamente documentos
contabilizados y aceptados por Hacienda; los demás documentos se presentan en
una auditoría separada.

Los valores del mismo atributo se combinan con OR y los atributos distintos
con AND. La clasificación usa la configuración actual de las variantes y
plantillas, también para movimientos históricos.
